## Findings

### P2-1: A failed sync does not stop a plan request

Status: fixed in `9c645d6a61c93d16324840e8aff57e9dd6d02305`.

Open at: `e2721cd532d7747708118802eff71aff51133e30`.

File: `web/src/lib/plan-api.ts:65-78`.

Trigger: An inventory entry waits in the outbox. `SyncOutbox` fails, but a later `RequestPlan` call succeeds.

Expected: Apply pending inventory changes before a plan request. A plan reads confirmed machines alone (D-193), and inventory changes use `SyncOutbox` (D-272).

Actual: `syncBeforePlan` runs the sync and checks for inventory entries that still wait. Both plan and exclusion calls stop with `InventoryNotSyncedError` when such an entry remains.

Consequence: The earlier behavior let the server build a plan from stale inventory. The new guard prevents this case.

Correction: Run `syncBeforePlan` before plan and exclusion calls, and show the sync error.

Regression check: `web/src/lib/sync.test.ts` checks a failed sync with a pending inventory entry. `web/e2e/plan.spec.ts` checks that no plan call starts before sync succeeds. Both checks are present. GitHub `verify:web` passed on this head.

### P2-2: A video probe cannot stop while its source is prepared

Status: open.

Open at: `9c645d6a61c93d16324840e8aff57e9dd6d02305`.

File: `web/src/pages/lock-test.tsx:35-41`.

Trigger: Start `Silent video file`, then tap Stop or leave the screen before `silentSource` completes its one-second recording.

Expected: Stop or screen exit stops the active probe (D-280, D-282), as the screen states.

Actual: `stopRef` remains null while `start` awaits `silentSource`. Stop clears the running state, but setup continues. When the await completes, `start` creates the probe and stores cleanup after the stop or unmount already ran.

Consequence: The probe can keep its event listeners and video source active after the owner stops it or leaves Diagnostics. The screen fails to stop this supported method.

Correction: Make source preparation cancellable, or store cleanup as soon as each resource starts and run it when Stop or unmount occurs.

Regression check: Add a test that delays video-file preparation. Stop or unmount the screen. Verify that no probe starts and all source resources stop.
